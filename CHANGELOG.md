## [1.0.0] — 2025-09-17

### Interview Transcript Summarizer
- Audio ingestion via OpenAI Whisper (mp3, mp4, wav, m4a, webm)
- PDF and DOCX transcript extraction
- Plain text paste input
- Full insight extraction: pain points, motivations, unmet needs, JTBD, persona signals
- Sentiment map per topic with intensity scoring
- Notable quotes with significance annotations
- Follow-up question generator (Must ask / Nice to have)
- PM action items (P0/P1/P2) by category
- Batch mode: analyze multiple .txt files at once
- Side-by-side comparison of two interviews
- Cross-interview pattern finder with Claude synthesis
- Interview library (session-based storage)
- PDF export (ReportLab)
- Research card HTML export (shareable one-pager)
- Notion push integration
- JSON export for all outputs
- Automated eval harness with 6 quality checks
- GitHub Actions CI
- Docker support
